# Laravel Ecommerce

This is a multi-vendor ecommerce application I built during my internship at FlexOps using Laravel and vue (with Inertia)

Tech Stack:
- Laravel
- Vue
- Tailwind
- Inertia

What did I learn while building this project:
- Using the Repository pattern to apply SOLID principles
- Handling complex relationships using the Eloquent ORM
- Caching data on a redis server
- Indexing and searching data using Laravel scout with Meilisearch driver
- Defining Policies to protect routes and models
- Using [spatie/laravel-medialibrary](http://spatie.be/docs/laravel-medialibrary/)
- Using [spatie/laravel-permission](https://spatie.be/docs/laravel-permission/)
- Building custom services using Laravels service container
- Authenticating Users
- Building robust components using vue and interact with the backend using Inertia's modules
- How to implement Faceted search functionality
